# Number Guessing Game / Jogo de Adivinhação 🎯

## 🇺🇸 English

### About the Project
An interactive terminal-based game where the user must guess a secret number. This project features a cumulative scoring system, win streaks, and dynamic difficulty levels. 

### Why I Built This
I developed this project to strengthen my programming logic and problem-solving skills—essential traits for optimizing administrative routines and creating efficient workflows. The core focus of this exercise was:
* Managing loop structures (`while`, `match case`).
* Understanding variable scopes and handling multiple function returns.
* Validating and processing user input.

### How to Play
1. Ensure Python is installed on your machine.
2. Clone this repository or download the main script.
3. Open your terminal and run the following command:
   ```bash
   python NUMBERGUESSING.py
